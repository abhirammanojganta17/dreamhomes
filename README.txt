# DreamHomes Real Estate Website

A polished front-end internship project built with **HTML, CSS and JavaScript**.

## Files
- `index.html` — main responsive website
- `login.html` — animated login page
- `style.css` — complete styling, responsive layout and animations
- `script.js` — preloader, scroll reveal, counters, search/filter, favourites, testimonials, mobile menu and demo login
- `assets/dreamhomes-icon.svg` — custom DreamHomes website icon / favicon

## Run
Open `index.html` in a browser. No installation or server is required for the demo.

## Backend note
The login, registration, property details, favourites and contact actions are front-end demo interactions. For a real application, connect them to a backend/database and replace the placeholder contact details.

## Suggested next upgrades
1. Add separate property-details pages.
2. Add an Add Property form.
3. Connect login/register to a backend.
4. Store properties in MySQL/MongoDB.
5. Add an admin dashboard.

Design note: the website does not use the uploaded reference image. Hero, property and About visuals are generated with CSS gradients and shapes.


## Design note
The uploaded reference image is not used. Property cards use real-estate photos loaded from Unsplash; the rest of the visual design is CSS/HTML based.
